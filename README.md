# Personal Dashboard

A responsive personal productivity dashboard built with React and JavaScript. The application allows users to manage tasks, track priorities, monitor progress, and maintain personal goals.

## Features

* Create, complete, and delete tasks
* Task priority levels
* Filter tasks by status
* Sort tasks by priority
* Task completion statistics
* Create and track personal goals
* Goal progress tracking
* Persistent data using browser localStorage
* Responsive interface built with Tailwind CSS

## Technologies

* React
* JavaScript
* Tailwind CSS
* Vite
* Browser localStorage

## What I Practiced

This project was built as a React warm-up project to reinforce core frontend development concepts and knock off some of the rust from being out of practice for a little bit.

Key concepts practiced:

* React components
* Props
* State management with `useState`
* Side effects with `useEffect`
* Controlled form inputs
* Event handling
* Conditional rendering
* Array methods including `map`, `filter`, and `sort`
* Component composition
* Responsive design
* Client-side persistence using `LocalStorage`

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
